# Amazon E-Commerce Web Application

A responsive Amazon-style e-commerce web application built using **HTML5, CSS3, and JavaScript (ES6+)**. The project provides a complete client-side shopping experience with product browsing, shopping cart management, checkout, order history, delivery options, and order tracking.

## Features

- Product browsing with 40+ products
- Product search
- Shopping cart management
- Product quantity management
- Checkout workflow
- Multiple delivery options
- Order history
- Order and delivery tracking
- Buy Again functionality
- LocalStorage-based data persistence
- Responsive user interface
- Jasmine unit tests

## Technologies Used

- **HTML5** – Structure and semantic markup
- **CSS3** – Styling, Flexbox, CSS Grid, and responsive layouts
- **JavaScript (ES6+)** – Application logic and DOM manipulation
- **LocalStorage** – Client-side data persistence
- **Jasmine** – JavaScript unit testing

## Application Pages

### Product Page

The main product page allows users to:

- Browse available products
- Search for products
- View product information
- Select product variations
- Add products to the shopping cart

### Checkout Page

The checkout page provides:

- Cart item summary
- Product quantity management
- Delivery option selection
- Order cost calculation
- Payment summary
- Order placement workflow

### Orders Page

The orders page allows users to:

- View previous orders
- View purchased products
- Check order details
- Buy products again

### Tracking Page

The tracking page provides:

- Order delivery status
- Delivery progress
- Estimated delivery information
- Product and order information
